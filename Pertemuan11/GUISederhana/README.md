## Kesimpulan
Perbedaan utama antara List, Set, dan Map terletak pada aturan penyimpanan dan cara mereka menangani data duplikat.

List bekerja layaknya sebuah daftar catatan biasa yang sangat memperhatikan urutan. Kamu bebas memasukkan data yang sama berkali-kali ke dalamnya, dan sistem akan tetap menyimpan semuanya secara utuh persis sesuai urutan waktu Anda memasukkannya melalui bantuan nomor indeks.

Sebaliknya, Set sangat ketat dalam menyaring keunikan data dan umumnya tidak memperdulikan urutan.

Sementara itu, Map memiliki pendekatan yang sama sekali berbeda karena selalu menyimpan data dalam format pasangan, yaitu Kunci (Key) dan Nilai (Value).
